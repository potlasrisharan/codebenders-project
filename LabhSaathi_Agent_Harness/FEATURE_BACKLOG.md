# LabhSaathi Feature Backlog

## P0 — PS5 and safety baseline

- Conversational typed intake; regional language where feasible.
- Adaptive questions, `I don't know`, and per-question "Why we ask this".
- Sensitive-ID Shield before persistence/logging/AI calls (client + server).
- Editable scheme records with official sources, verification dates and rule versions.
- National state-aware user flow with a transparent state/category coverage registry; hackathon demo cohort is low-income college students in Telangana.
- Three-valued eligibility engine (`true` / `false` / `unknown`).
- Fixed labels: `Likely eligible`, `Need to confirm`, `Unlikely`, `Can't tell yet`.
- Per-condition reasoning and tests forbidding bare "eligible", "guaranteed" and "approved" outcome language.
- Personalised document checklist and sourced application steps.
- Official application link, fee transparency and Middleman Shield on every scheme page.
- Saved schemes, basic claim tracker, verified deadline reminders.
- Six synthetic student personas and golden eligibility tests.

## P1 — high-value differentiators

- Telugu/English quality improvements and voice input.
- Near-Match Discovery (same eligibility engine).
- WhatsApp checklist share (`wa.me`, preview-first, no personal data/API).
- Academic-year renewal calendar with source-verified scheme-specific dates.
- Unified Eligibility Action Graph (one graph, not two separate features).
- What-If Eligibility Simulator (same canonical engine, hypothetical only).
- Scheme Change Radar with controlled demo data and rule diff/impact view.
- Admin data-quality and source-review queue.
- Source conflict and stale-data flags.
- State/category coverage registry to distinguish data gaps from no matching schemes.
- Scheme comparison and printable checklist.

## P2 — future / not required for hackathon MVP

- Rejection Recovery Assistant.
- Full NGO caseworker / multi-tenant dashboard.
- Benefit Passport.
- Production CSR analytics and paid institutional workspace.
- Nationwide multi-population scheme coverage.
- Live broad-spectrum source monitoring and advanced ingestion automation.
