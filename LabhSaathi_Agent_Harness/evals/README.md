# LabhSaathi Skill Evaluation Prompts

`skill-evals.json` contains two initial realistic prompts for each of the 29 skills. These are starter scenarios, not claimed passing evaluations.

Use the prompts in Nexen to check whether the agent:
- activates the appropriate skill;
- obeys phase/owner approval boundaries;
- preserves PS5 and privacy constraints;
- avoids inventing scheme information;
- reports test and source evidence honestly.

Record observed failures and revise the relevant skill. Do not claim the harness is behaviorally validated merely because the Markdown files parse. A future stronger evaluation should run paired scenarios with/without the skill and inspect actual agent behavior.
